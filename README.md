# HabotConnect Junior Cloud & DevOps Engineer — Hiring Project

## Project Overview

This repository contains the technical submission for the
Junior Cloud & DevOps Engineer (GCP / Django / React) hiring project
at Habot Connect FZCO.

The project focuses on secure cloud infrastructure, automated
fail-closed CI/CD controls, and deterministic data validation.

## Project Objectives

The implementation addresses the three required technical tasks:

1. Terraform Secure Staging Provisioning
2. Poka-Yoke Automated CI/CD Build Gate
3. Schema Mapping and DCYN Validation
